# Analysis decisions frozen before the new run

Date: 2026-09-17. Dataset already explored; this is not preregistration. Source: docs/PLAN.md and Mengxi's attachment. This file records implementation defaults; amendments and failures are in the run logs.

- Seed 20260917; preserve input workbook hash. Primary CE0 is application. No direction/significance required for success.
- Four separately modeled tolerance items are primary, oriented as stored; Holm correction within the four application coefficients for each adjustment family. Three/four-item equal-weight raw means are secondary. Standardize outcomes only when reporting SD contrasts, with scale documented.
- Background: county, NP, age, gender, education as a factor, household size. Resources: log1p income, agriculture percentage, log1p total area, log1p livestock, log1p total assets. Simultaneous attitudes/exposure are a separate explanatory set.
- Reporting count from raw Q17; missing raw responses remain missing; mixed “no report” + institution is counted by named institutions and flagged, with exclusion sensitivity. PS1 stored is never interpreted as an increasing institution count.
- Percentage >1 becomes NA in validated preference fields; retain original columns for sensitivity. Areas stay in recorded units (provisionally mu). Damage>area retained and flagged. CE1/CE2 absent raw responses are restored to NA; non-applicant values remain structural NA. Tol1 raw missing is restored to NA in the primary derived item.
- Word zeros become NA. Primary IC descriptor is the mean of available words; number of words is retained. No imputation of nonexistent words. Incidental missingness: complete-case primary, transparent median/mode single-imputation sensitivity only for the few observed-covariate gaps; no claim that this captures imputation uncertainty.
- EFA/CFA ordinal sparse-end categories: use the original five categories first; any collapse is explicitly labeled sensitivity, not an unreported preprocessing choice. Theory CFA: correlated tolerance and IC factors versus one factor, four-item versus three-item tolerance. Core EFA considers 1–3 factors with parallel analysis; no outcome-driven item deletion.
- Grouped internal split uses entire villages, balancing county and CE0 counts by deterministic seeded search. Missing village receives an ID-specific group. No external validation claim.
- Primary uncertainty clusters townships with finite-cluster t inference; village and HC3 sensitivity. No two-county cluster SE. County is fixed; township multilevel models complement clustered regressions.
- PLS indicators: tolerance three items (Tol1/Tol2/Tol4), IC1 plus available-word mean (formative); institutions count+PS2 (formative); log damage+log loss (formative); IB and CE0 observed. Sensitivities include four-item tolerance and IC1 alone. Composite scores do not establish trust or fatigue.
- Bootstrap sample whole townships separately within county; 2,000 main resamples, 5,000 principal-path stability resamples; export every valid/failing replicate and failure rate. The same bootstrap stream can be extended from 2,000 to 5,000.
- Prediction: fixed 5 outer township folds, 3 inner township folds; benchmark/elastic net/GAM/RF/boosting; tune only on inner folds; impute/scale from training data only. County transfer is two descriptive transport checks.
- Bayesian: cumulative-logit random township intercept, Normal(0,1) standardized slopes, exponential(1) SD, four chains; R-hat <=1.01, bulk/tail ESS >=400, zero divergences. Failed diagnostics prohibit treating posterior intervals as final.
- Specification curves separately show outcome/adjustment definitions; no p-curve or claim to prove absence of p-hacking. Deduplicate identical design/response/sample specifications. Preserve failed fits and all tested alternatives.
- No causal mediation claims, no evidence-of-equivalence claim from nonsignificance, no blanket alpha/HTMT criteria for formative composites. All renderings read saved numerical outputs.
